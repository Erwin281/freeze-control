# ❄️ Freeze Control - Elige qué vive, el resto se congela

### Instalar en Chrome / Edge / Brave (gratis)
1. Dale a Code -> Download ZIP
2. Descomprime el ZIP
3. Ve a `chrome://extensions` -> Activa Modo Desarrollador
4. Dale a "Cargar descomprimida" -> Elige la carpeta

### Instalar en Firefox (gratis)
1. Descarga el ZIP
2. Ve a `about:debugging#/runtime/this-firefox`
3. Dale a "Load Temporary Add-on" -> Elige el `manifest.json`
